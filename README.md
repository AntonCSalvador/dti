# dti

An AI outfit companion for Dress To Impress: type a theme, discover live visual references, and get an achievable outfit recipe using standard/free items.

## V1: Find a look and dress manually

- Type the round's theme and choose feminine, masculine, or either outfit styling.
- Search live for relevant celebrity, character, and fashion reference images.
- Match references against a prepared catalog of standard/free dressing-room items.
- Account for avatar compatibility, item toggles, layering, and recoloring.
- Present up to three achievable looks with source images and links.
- Provide item thumbnails, names, verified locations, toggles, colors, and assembly order.
- Explain missing details and uncertain matches so players can choose quickly.
- Apply the outfit manually in Roblox.

VIP, paid, code, and event-unlock items are outside the initial inventory.

## V2: Dress through the Roblox desktop app

Extend the outfit recipe into game control: navigate to items, equip them, apply toggles and colors, inspect the result, and make corrections. Desktop-control feasibility and reliability must be validated before implementing this release.

## Project status

Planning stage; no application has been implemented yet. See the [v1 design](docs/superpowers/specs/2026-10-10-dti-design.md).
